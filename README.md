# 🎮 Pokémon Quiz

A fun, interactive Pokémon quiz game built using HTML, CSS, and JavaScript.

## ✨ Features

- Interactive multiple-choice questions about Pokémon
- Four answer options for each question
- Progress bar to track quiz progress
- Score/result screen
- Play Again option to restart the quiz
- Pokémon-themed images and interface

## 🛠️ Technologies Used

- HTML5 — Structure
- CSS3 — Styling and layout
- JavaScript — Quiz logic and interactivity

## 📁 Project Structure

```text
Pokemon-Quiz/
├── index.html
├── style.css
├── script.js
├── Pikachu.jpg
└── Pokeball.png
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Click the start button and enjoy the quiz!
